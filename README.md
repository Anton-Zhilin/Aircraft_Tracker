# Aircraft Tracker

---
## Описание проекта:

Приложение для мониторинга воздушного пространства. 
Собирает данные о самолётах в реальном времени, позволяет фильтровать, сортировать и сохранять результаты.
---
## Возможности:

- Получение информации о самолётах в воздушном пространстве любой страны
- Геокодирование через Nominatim (OpenStreetMap)
- Данные о полётах через OpenSky Network API
- Фильтрация по стране регистрации, диапазону высот, скорости и статусу (в воздухе / на земле)
- Сортировка и выборка топ-N самолётов по высоте
- Сохранение и загрузка данных в JSON-файл
---
## Технологии:

- Python 3.14
- Poetry — управление зависимостями и виртуальным окружением
- requests — HTTP-запросы
- unittest + unittest.mock — тестирование
---
## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.14+ и Poetry
2. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:Anton-Zhilin/Aircraft_Tracker.git
3. Установите зависимости с помощью Poetry:
   ```bash
   poetry install

4. Запуск приложения:
   ```bash
   poetry run python main.py
   ```
